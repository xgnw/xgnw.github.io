数据源设置

默认读取同目录 hot-data.js（由 node fetch-hot.js 生成的快照）。
填「自建后端地址」即可切换为实时取数——后端（Worker 或 server.js）会代理上游热榜接口并缓存，页面只管拉 JSON。

自建后端接口返回任意一种即可： { sources:[{name, cat, icon, url, items:[{title,url,hot}]}] } · { data:[{title, hot_value, link}] } · [ {title, url} ]
后端常用端点：/all 全量聚合 · /zhihu 单榜 · /probe/zhihu 探测上游 · /health 健康检查
数据来自 tophub · 今日热榜，每小时更新一次
