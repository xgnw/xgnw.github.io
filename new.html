关于本站

本站是怎么做出来的

  1. 本站脱胎于 简单导航网（432600.xyz）的开源「简单导航」模板，在其基础上做二次开发。
  2. 导航数据集中维护在页面底部的 NAV_DATA 数组里，改数据即改页面，不需要任何构建工具或后端服务。
  3. 管理工作独立成 admin.html：在 Chrome / Edge 里直接用浏览器读写本机 index.html（File System Access API），可增删分类 / 链接 / 搜索引擎并一键写回，无需起服务。
  4. 卡片网格采用 CSS Grid auto-fill 自适应列数，分类下只有少数链接时也不会被拉伸铺满整行。
  5. 主题支持浅色 / 深色 / 跟随系统，偏好存于 localStorage。
